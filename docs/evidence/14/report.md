Projection preserves the supplied list and does not resolve that overlap.
3. **Split description spans, all screenshots:** temple name, culture, food and production are separate reference rows. Visible parentheses, semicolons and the statistics grouping are not represented as complete continuous text spans. A finding joining two rows, including such separators, may not be identified as present even if its parts are visible. The combined `Archer (5…, 7…)` / `Bogenschütze (5…, 7…)` span is likewise absent as a full unit. Icons are excluded by #10; no icon transcription or joining rule is invented here.

The reference represents full rows, not each embedded text occurrence. It supplies no policy for treating those embedded words as identical independent occurrences for region disambiguation. The whole production finding therefore cannot be validated as on-screen by the approved visible-prefix row alone. That is an explicit visibility boundary, not permission to add the hidden suffix.
7. **Exact punctuation across UI fragments:** headings include colons in reference rows; OCR can omit them, while adjacent description punctuation is not fully encoded.
